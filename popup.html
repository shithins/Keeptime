  1. Create a new **blank Google Sheet** in your Google Drive.
  2. Open **Extensions > Apps Script** in your sheet.
  3. Paste the code from `google-apps-script.js`.
  4. Click **Deploy > New deployment**, select **Web app**, set Execute as **Me**, and Access to **Anyone**.
  5. Deploy, copy the Web App URL, and paste it below.
